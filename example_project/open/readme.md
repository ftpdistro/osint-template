# About this directory

The following folder structure in ``` osint101-folder-template/example_project/open/ ``` is meant to house all OSINT (open-source intelligence)

| Folder       | Description              |
|--------------|--------------------------|
| CONCEPTINT   | Conceptual Intelligence                     |
| EVENTINT     | Event Intelligence                 |     
| FININT       | Financial Intelligence                 | 
| GEOINT       | Geospatial Intelligence                     |
| HUMINT       | Human Intelligence                 |     
| IMAGEINT     | Image & Video Intelligence                 | 
| RUMINT     | Rumor Intelligence                 | 
| SIGINT       | Signals Intelligence                     |
| TOOLINT      | Tool Intelligence                 |     
| unsorted     | All files and folder to be sorted, as a triage. Ideal for large amounts of data that is scraped automatically using scripts.                 | 
| zip          | Compressed versions of a project, with the timestamp in the filename (12-23-2021-example_project.zip).                         |
